# Evolving Atmosphere

[Documentation home](../README.md) · [All visualizers](README.md)

Plasma, ribbons, tunnel rings, petal folds, and particles blend together. Kicks launch shockwaves; treble stretches particle trails.

Select **Evolving Atmosphere** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.4` | Scene brightness. |
| `hue` | `0.62` | Palette shift through a full color cycle (0–1). |
| `warp` | `1` | Pattern or geometry distortion. |
| `evolution` | `1` | Rate of change between atmospheric forms. |
| `particles` | `1` | Particle contribution. |
| `ambient` | `false` | Enables motion during silence. |
