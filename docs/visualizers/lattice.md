# Vector lattice

[Documentation home](../README.md) · [All visualizers](README.md)

Warped perspective neon grids and horizon beacons.

Select **Vector lattice** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.3` | Scene brightness. |
| `warp` | `1` | Pattern or geometry distortion. |
| `hue` | `0.72` | Palette shift through a full color cycle (0–1). |
