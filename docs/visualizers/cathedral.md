# Laser cathedral

[Documentation home](../README.md) · [All visualizers](README.md)

Concert laser fans sweep across a polygonal prism.

Select **Laser cathedral** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.9` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.35` | Scene brightness. |
| `symmetry` | `6` | Number of angular repetitions (2–12). |
| `hue` | `0.82` | Palette shift through a full color cycle (0–1). |
