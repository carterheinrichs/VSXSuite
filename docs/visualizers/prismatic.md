# Prismatic drift

[Documentation home](../README.md) · [All visualizers](README.md)

Travel through twisting prismatic hoops.

Select **Prismatic drift** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.95` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.3` | Scene brightness. |
| `twist` | `1` | Twisting of the tunnel or spiral. |
| `hue` | `0.55` | Palette shift through a full color cycle (0–1). |
