# Hubble Ring ON ACID

[Documentation home](../README.md) · [All visualizers](README.md)

An oval nebula shell combines a blue interior, rainbow filaments, liquid distortion, and outer echoes. Bass breathes the ring; attacks illuminate filaments and stars.

Select **Hubble Ring ON ACID** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.7` | Scene brightness. |
| `hue` | `0` | Palette shift through a full color cycle (0–1). |
| `warp` | `1` | Pattern or geometry distortion. |
| `stars` | `1` | Star brightness and spikes. |
| `reactivity` | `1` | Music response strength; zero removes audio modulation. |
