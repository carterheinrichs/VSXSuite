# Lissajous scope

[Documentation home](../README.md) · [All visualizers](README.md)

A two-dimensional waveform scope produces looping figures.

Select **Lissajous scope** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `intensity` | `1.2` | Scene brightness. |
| `gain` | `1` | Visual audio gain without changing listening volume. |
| `hue` | `0` | Palette shift through a full color cycle (0–1). |
