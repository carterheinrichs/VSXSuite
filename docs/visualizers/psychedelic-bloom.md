# Psychedelic Bloom

[Documentation home](../README.md) · [All visualizers](README.md)

Nested petal rings fold into a breathing kaleidoscope.

Select **Psychedelic Bloom** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.85` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.2` | Scene brightness. |
| `hue` | `0.04` | Palette shift through a full color cycle (0–1). |
| `warp` | `1` | Pattern or geometry distortion. |
| `symmetry` | `8` | Number of angular repetitions (2–12). |
