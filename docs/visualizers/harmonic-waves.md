# Sine + cosine waves

[Documentation home](../README.md) · [All visualizers](README.md)

Two or three colored sine and cosine traces form harmonic waves.

Select **Sine + cosine waves** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `intensity` | `1.2` | Scene brightness. |
| `gain` | `1` | Visual audio gain without changing listening volume. |
| `hue` | `0` | Palette shift through a full color cycle (0–1). |
| `waveCount` | `3` | Chooses two or three traces. |
| `frequency` | `1` | Wave cycles across the frame. |
| `amplitude` | `1` | Wave height. |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `separation` | `0.35` | Vertical spacing between traces. |
| `thickness` | `1` | Trace thickness. |
