# Pulse Reactor

[Documentation home](../README.md) · [All visualizers](README.md)

A bass-reactive core is surrounded by waveform rings and kick shockwaves.

Select **Pulse Reactor** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.3` | Scene brightness. |
| `hue` | `0.45` | Palette shift through a full color cycle (0–1). |
| `warp` | `1` | Pattern or geometry distortion. |
