# Acid Chrome

[Documentation home](../README.md) · [All visualizers](README.md)

Flowing ripples catch metallic highlights and iridescent reflections.

Select **Acid Chrome** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.8` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.15` | Scene brightness. |
| `hue` | `0.18` | Palette shift through a full color cycle (0–1). |
| `warp` | `1.1` | Pattern or geometry distortion. |
