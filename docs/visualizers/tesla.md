# Tesla plasma web

[Documentation home](../README.md) · [All visualizers](README.md)

Branching waveform lightning arcs across electrodes.

Select **Tesla plasma web** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `1.05` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.4` | Scene brightness. |
| `warp` | `1.2` | Pattern or geometry distortion. |
| `hue` | `0.62` | Palette shift through a full color cycle (0–1). |
