# Hubble Nebula

[Documentation home](../README.md) · [All visualizers](README.md)

Gold and cyan clouds, dust pillars, stars, and diffraction spikes evoke telescope imagery. Bass bends clouds, mids shift color, and beats launch illumination fronts.

Select **Hubble Nebula** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.6` | Scene brightness. |
| `hue` | `0` | Palette shift through a full color cycle (0–1). |
| `dust` | `1` | Strength of dark dust structures. |
| `stars` | `1` | Star brightness and spikes. |
| `drift` | `1` | Cloud drift and displacement. |
| `reactivity` | `1` | Music response strength; zero removes audio modulation. |
