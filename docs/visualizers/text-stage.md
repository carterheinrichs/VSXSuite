# Text Stage

[Documentation home](../README.md) · [All visualizers](README.md)

Custom typography floats and pulses over a solid, wave, or ring background.

Select **Text Stage** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `text` | `FEEL THE MUSIC` | Text content; a vertical bar starts a new line. Limited to 1,000 characters and eight lines. |
| `font` | `sans-serif` | Modern (sans-serif), Editorial (serif), or Terminal (monospace). |
| `color` | `#63f5ff` | Text color. |
| `background` | `#070b18` | Background color. |
| `backgroundEffect` | `1` | Background style: Solid (0), Waves (1), or Rings (2). |
| `size` | `0.65` | Text size. |
| `tracking` | `0.02` | Letter spacing. |
| `bold` | `true` | Toggles heavier typography. |
| `motion` | `1` | Float & pulse: drifting and pulsing text motion. |
| `glow` | `1.2` | Glow around text or curves. |
| `reactivity` | `1` | Music response strength; zero removes audio modulation. |

Canvas artwork is capped at 1,536 pixels on its longest edge.
