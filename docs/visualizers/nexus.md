# Nexus spectrum

[Documentation home](../README.md) · [All visualizers](README.md)

A 48-band radial analyzer with peak caps and an inner waveform turbine.

Select **Nexus spectrum** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.95` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.35` | Scene brightness. |
| `spread` | `1.1` | Spacing and spread of light structures. |
| `hue` | `0.38` | Palette shift through a full color cycle (0–1). |
