# Recursive Chrome

[Documentation home](../README.md) · [All visualizers](README.md)

Travel through rainbow metal frames and interlocking gear teeth. Bass contracts the corridor, spectrum bands extend teeth, and kicks accent travel.

Select **Recursive Chrome** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.7` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.15` | Scene brightness. |
| `hue` | `0.08` | Palette shift through a full color cycle (0–1). |
| `warp` | `1` | Pattern or geometry distortion. |
| `symmetry` | `9` | Number of angular repetitions (2–12). |
