# Retro plasma

[Documentation home](../README.md) · [All visualizers](README.md)

Flowing demoscene color fields respond to music with optional scanlines.

Select **Retro plasma** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `intensity` | `1.2` | Scene brightness. |
| `gain` | `1` | Visual audio gain without changing listening volume. |
| `hue` | `0` | Palette shift through a full color cycle (0–1). |
| `speed` | `1` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `scale` | `1` | Plasma spatial frequency; higher values fit more detail in the frame. |
| `colorCycles` | `1` | Palette repetitions across the plasma field. |
| `distortion` | `1` | Audio-driven plasma distortion. |
| `scanlines` | `true` | Toggles horizontal scanline shading. |
