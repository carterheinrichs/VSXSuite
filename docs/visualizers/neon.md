# Neon feedback

[Documentation home](../README.md) · [All visualizers](README.md)

A kaleidoscopic neon vortex with feedback trails and spectral history.

Select **Neon feedback** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `persistence` | `0.91` | Previous-frame retention; higher values make longer trails. |
| `symmetry` | `6` | Number of angular repetitions (2–12). |
| `intensity` | `1.25` | Scene brightness. |
| `warp` | `0.3` | Pattern or geometry distortion. |
| `hue` | `0.0` | Palette shift through a full color cycle (0–1). |
