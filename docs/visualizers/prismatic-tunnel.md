# Prismatic Tunnel

[Documentation home](../README.md) · [All visualizers](README.md)

Twisting eight-sided spectral walls form a continuous tunnel.

Select **Prismatic Tunnel** in the library and expand its rack folder. [Shared controls, overlays, and master FX](../using-vsxsuite.md) apply to this scene and exports.

## Options

Parameter names are listed below; explanations include differing display labels. Defaults are the initial app values.

| Option | Default | What it does |
| --- | --- | --- |
| `speed` | `0.85` | Animation speed; zero stops time-driven motion, though audio changes may remain. |
| `intensity` | `1.25` | Scene brightness. |
| `hue` | `0.65` | Palette shift through a full color cycle (0–1). |
| `warp` | `1` | Pattern or geometry distortion. |
| `twist` | `1` | Twisting of the tunnel or spiral. |
